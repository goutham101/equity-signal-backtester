# dashboard/data

Generated by `scripts/06_export_dashboard_data.py`. Don't edit these files by hand.

They are the only data the Streamlit app reads. The file layout and columns are in
`docs/dashboard_data_contract.md`. To refresh them, run scripts 01–05 first, then:

```bash
.venv/bin/python scripts/06_export_dashboard_data.py
```

Script 06 never logs to `backtest_runs`. These files are committed on purpose:
Streamlit Community Cloud can't reach the local Postgres. Floats are stored as
float64 (the whole folder is about 3 MB).
